ABOUT VELVET PROXY

Help & limitations

HTTP / HTTPS can use username and password. HTTPS means an encrypted connection to the proxy itself, not merely access to an HTTPS website.

SOCKS4 / SOCKS5 work only without username/password in Chrome. Ask your provider for IP authentication or an HTTP endpoint.

Live verification: checks api.ipify.org through the candidate proxy and compares the response with your direct-connection public IP. Same-IP or unavailable baseline shows UNVERIFIED. A failure can also mean the test service is blocked, not necessarily a permanently dead proxy.

Location: ipwho.is provides approximate country and city from the observed IP. Location may be missing or inaccurate. Verified flags use the flag.img SVG provided by ipwho.is (cdn.ipwhois.io), with a country emoji fallback. The toolbar icon is red when a proxy is active and slate when disabled.

Turning off removes this extension's proxy override, returning control to Chrome's other proxy settings. Another extension, VPN, enterprise policy, or browser flag may override this extension.

Privacy: Profiles and passwords are stored locally in Chrome's extension storage, not encrypted by this extension. There are no analytics or cloud accounts. Verification requests contact ipify and ipwho.is only when you explicitly add, import, connect, or test a proxy. Chrome browser proxy settings do not guarantee coverage of WebRTC or other applications.
